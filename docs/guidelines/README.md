# Sonzra Tizen TV Guidelines

This directory contains the canonical engineering, design, and UI/UX guidelines for the Sonzra Samsung Smart TV application.

## Index

1. [Architecture Guidelines](architecture.md): Spatial navigation state, component hierarchies, context boundaries, API client decoupling, and hardware key handling.
2. [UI & UX Guidelines](ui_ux.md): 10-foot Smart TV principles, remote D-pad ergonomics, visual contrast at distance, focus indicators, and persistent playback continuity.
3. [Design System](design_system.md): Tailwind tokens, OLED dark palettes, typography, glowing halo rings, and component specifications.
